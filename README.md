# Simple Calculator

A simple program that just _calculates_. I know that computer has their own limitations like the precision, Something like floating number IEEE 754.

But anyway i made this because it's simple and i learned __Makefile__ and also __C Stream Buffer__.

### Compile and Run

to compile:
```bash
make
```

to run:
```bash
make run
```

to remove:
```bash
make clean
```

I'm newbie on Makefile so... Keep it simple
